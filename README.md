# Классификация кожных патологий с использованием сверточных нейронных сетей (CNN)

## Описание проекта
Данный репозиторий содержит материалы **курсовой работы**, посвященной автоматизации процесса диагностики кожных заболеваний. В рамках работы решается **задача многоклассовой классификации** дерматоскопических изображений с целью выявления меланомы и других новообразований на ранних стадиях.

## Датасет
Для обучения и валидации использован **Skin Cancer MNIST: HAM10000** (*Human Against Machine с 10 000 изображений*). Каскад проверен на 1512 снимках официального теста ISIC 2018 Task 3.

Датасет включает в себя 10 015 дерматоскопических снимков, распределенных по 7 категорий патологий кожи:
1. Меланома (`mel`)
2. Меланоцитарный невус (`nv`)
3. Базальноклеточная карцинома (`bcc`)
4. Актинический кератоз / внутриэпителиальная карцинома (`akiec`)
5. Доброкачественное кератоподобное новообразование (`bkl`)
6. Дерматофиброма (`df`)
7. Сосудистые новообразования (`vasc`)

## Стек технологий
* **Язык программирования:** Python
* **Библиотеки глубокого обучения:** PyTorch
* **Обработка данных и визуализация:** NumPy, Pandas Matplotlib ...

## Ключевые особенности реализации
* **Архитектура:** Использование глубоких сверточных нейронных сетей (CNN).
* **Оптимизация:** Алгоритм **Adam / AdamW** с адаптивным подбором шага обучения.
* **Функции активации:** Послойная обработка с помощью **ReLU** (в скрытых слоях) и **Softmax** (на выходном слое для многоклассовой вероятностной оценки).
* **Аугментация данных:** Применение методов вращения, масштабирования и цветового сдвига для борьбы со дисбалансом классов в датасете HAM10000.

## Каскад ProSkin

Каскад использует энтропию ответа базовой модели и её предсказанный класс, чтобы выбрать одного из шести специалистов. Веса, порядок выходных классов и истории обучения доступны в [my-models/specialists](my-models/specialists). Архитектуры и кривые обучения собраны в [graphics/proskin-specialists](graphics/proskin-specialists).

На тесте macro F1 базовой ProSkin составил **0,4870**. При порогах 0,30 и 0,40 каскад показал соответственно **0,3645** и **0,3756**. При переборе 101 порога максимум macro F1 составил **0,4876** при 0,82. Общее число ошибок при этом увеличилось с 485 до 487, а порог был найден на этой же тестовой выборке.

## Как повторить расчёт

1. Установите зависимости командой `python -m pip install -r requirements.txt`.
2. Скачайте [HAM10000 на Kaggle](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000) или из [Harvard Dataverse](https://doi.org/10.7910/DVN/DBW86T). Поместите `HAM10000_metadata.csv` и папки с JPEG `HAM10000_images_part_1` и `HAM10000_images_part_2` в папку `data/` у ноутбука. Полный датасет скачивается отдельно. Три снимка из эксперимента доступны в [graphics/examples](graphics/examples).
3. Откройте `main.ipynb` из корня проекта. Для проверки на сохранённых весах выполните ячейку с функцией `color_transition_entropy_n`, затем ячейку под заголовком «Связь энтропии изображения и ответа ProSkinCNN». Эта ячейка загружает веса, строит графики и сохраняет CSV без обучения.

Для теста каскада скачайте архивы `ISIC2018_Task3_Test_Input.zip` и `ISIC2018_Task3_Test_GroundTruth.zip` из строки Task 3 на [странице данных ISIC 2018](https://challenge.isic-archive.com/data/#2018) и поместите их в `data/isic2018-test/` без распаковки. Запустите из корня проекта:

```sh
python evaluate_proskin_cascade.py --threshold 0.3
python evaluate_proskin_cascade.py --threshold 0.4
python sweep_proskin_thresholds.py
```

Для повторного обучения специалистов используется `python train_proskin_specialists.py --epochs 20 --patience 5`. В опубликованном запуске этот параметр задавал до 20 эпох и раннюю остановку после пяти эпох без улучшения валидационного macro F1.
